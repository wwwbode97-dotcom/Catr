# متحكم كاتر بلوتر 365

تطبيق ويب للتحكم في كاتر بلوتر عبر USB OTG أو بلوتوث، مع مكتبة تصميمات الموبايل (٢٨٣٧ تصميم).

## الملفات
- `index.html` : التطبيق كامل (والمكتبة داخله)
- `manifest.webmanifest` + `icon-192.png` + `icon-512.png` : لتثبيته كتطبيق على الموبايل
- `sw.js` : لتشغيله بدون إنترنت بعد أول فتح

## التشغيل عبر GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root)
ثم افتح الرابط من Chrome على الموبايل.
